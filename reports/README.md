# Sample reports

Full end-to-end research reports, one markdown file per symbol, generated by the multi-agent pipeline.

| File | Symbol | Status |
|---|---|---|
| [`UNIPARTS.md`](UNIPARTS.md) | Uniparts India Ltd. (NSE) | ✅ complete run, 2026-10-06 |
| `POLICYBZR.md` | PB Fintech / Policybazaar (NSE) | ⏳ pending |

Each report contains the five pipeline stages: analyst team reports, research-team decision,
trading plan, risk-team debate and the portfolio manager's final rated call.

**Note on `POLICYBZR`:** an earlier attempt aborted mid-debate on the LLM provider's request-size
limit (HTTP 413). The pipeline now caps embedded report/history size (see `report_char_budget` and
`debate_history_chars` in `copilot/config.py`), so a clean run is possible — this sample will be
added once captured.

To generate one yourself:

```bash
uvicorn server:app --port 8000
# open http://localhost:8000, AI Research tab, set symbol + provider, Run analysis
# then copy runs/<id>/complete_report.md into this folder
```
